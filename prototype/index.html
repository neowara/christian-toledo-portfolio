// mobile + backend

Turbo

An Android app and self-hosted backend for tracking rides on a modified electric skateboard, with direct Bluetooth control of the board itself, not just GPS logging.

App repo ↗ Backend repo ↗ Read the deep dive →
  • Direct BLE, no cloud dependency: reverse-engineered the board's Bluetooth protocol to read and write live telemetry and settings directly, battery, voltage, ride mode, acceleration curves, bypassing Tuya Cloud entirely.
  • Physics-based range estimation: the backend fits a per-mode model of rolling resistance, aerodynamic drag, and drivetrain efficiency from real ride history, instead of a linear battery-percent guess.
  • Clean GPS from noisy hardware: raw phone GPS gets road-snapped through a self-hosted OSRM instance and enriched with weather, so a route doesn't visibly cut through buildings.
  • Real auth, not a shared token: per-user accounts, argon2id password hashing, session-based API access, and an admin panel for account and data management.

// infrastructure

casa-verde

A home lab run with the same rigor as production infrastructure: not a pile of Docker containers, a system with a documented history of every real decision behind it.

Repo ↗ Read the deep dive →
  • ~10 services on one Proxmox host: media automation, a photo/music library, DNS, a self-hosted voice assistant, a modded game server, each isolated in its own LXC container.
  • Infra as code, deliberately split: Ansible for most stacks, GitOps (Komodo) for the ones where webhook-speed redeploys are worth the added complexity, chosen per stack, not dogmatically.
  • 80+ written ADRs: every non-trivial decision, including the ones that didn't work and had to be reverted, has a documented reason, not just a diff.
  • Actually monitored: daily drift detection against git, automated backups, and real alerting (ntfy) for failures, not just "the container is still running."
